One line roasting my own agent for make.fun's "Roast Your Own Agent" bounty: the agent that says "let me verify that", verifies the verification, then asks me to double-check its double-check — a three-beat escalation on the verification loop every agent falls into.

## Run it

```sh
python3 main.py
```

This writes the roast to `/output/entry.txt` (one line, 115 characters).
